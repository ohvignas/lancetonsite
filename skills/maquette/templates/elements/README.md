## Mode aperçu

Chaque démo s'ouvre aussi en `<nom>.html?apercu` : l'élément seul, plein cadre, sans texte d'explication (tout ce qui explique porte `data-explication`). Les captures de `captures/` sont faites dans ce mode. Chaque fiche porte une ligne `apercu:` et une section « Prompt pour le régénérer » prête à coller.

Déjà couverts par le kit, donc non refaits : compteurs (`data-counter`), texte en cascade (`data-split`, `data-intro`), défilement de logos (`data-marquee`) — voir `../prototype/GESTES.md`.

## Règles communes

- Choisir d'après la fiche de `commun/compositions.md`, pas l'inverse : un élément sert le moment signature ou une section, il n'est pas une décoration de plus.
- Tout ce qui bouge seul a une pause et s'arrête hors écran ; tout ce qui se pilote au pointeur a un équivalent clavier ou un bouton.
- Mouvement réduit vérifié pour chaque démo ; couleurs et tailles en variables CSS à brancher sur les tokens.
- Les médias de démo viennent des exemples du plugin (`../exemples/`) ; `medias/versement-960.*` est un ré-encodage de la vidéo de Brume. Aucune génération payante.
