    03 Comment ça marche

    Trois gestes, douze étapes

    Le plugin s'installe une fois. Ensuite, un prompt suffit pour lancer tout le parcours, de la première question à la mise en ligne.

    1. 1

      Installer le plugin

      Dans Claude Code, ouvert dans un dossier vide au nom de votre site, collez ces deux lignes.

      claude
      /plugin marketplace add ohvignas/lancetonsite
/plugin install lancetonsite@lancetonsite-marketplace
    2. 2

      Copier un prompt

      Choisissez l'exemple le plus proche de votre métier et cliquez sur « Copier le prompt ». Il garde le design et laisse des crochets pour vos infos.

      prompt · Brume
      /lancetonsite:demarrer

Je veux un site dans le style de l'exemple Brume…
Mes infos : [Nom de mon entreprise] · [Mon métier] · [Ma ville]…
    3. 3

      Lancer

      Collez, remplacez les crochets, envoyez. Le plugin enchaîne les étapes et attend votre accord avant chacune.

      1. Cadrage
      2. Marque
      3. Charte
      4. Architecture
      5. Contenus
      6. Design system
      7. Médias
      8. Maquette
      9. Vérification
      10. PRD
      11. Construction
      12. Mise en ligne
